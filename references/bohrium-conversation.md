# Bohrium 对话结果整理

适用于用户要求读取 Bohrium 科学导航或学术搜索对话，整理其研究问题分析、综述、文内引用、右侧参考文献或“全部搜索结果”。这是读取用户可访问内容并核验文献的工作流，不代表接入 Bohrium 私有数据库或复现其内部搜索。

## 获取与界定范围

1. 优先使用用户给出的对话分享链接、导出的文献列表或页面内容。若用户已在可控制的浏览器中打开对话，且工具能访问该页面，可读取页面；遵守登录与访问限制，不索取密码、会话令牌或绕过验证。截图只能证明可见区域的内容。分享页若需要登录或无法加载，说明限制，并继续处理用户提供的可读内容。
2. 先记录对话主题、生成日期（若可见）、页面显示的“参考 N 篇”等计数，以及用户需要的范围：综述引用、右侧参考文献、全部搜索结果可能是不同集合。按用户要求选择集合；范围未明确时分别列明，不把一个集合冒充另一个。
3. 对可访问的引用面板逐页或滚动读取到末尾，保留原始编号、题目、作者、年份、来源、详情链接及对话中的引用标记。仅在实际获取全部条目时声明“全部”。若页面只显示前若干条、分页无法访问、截图不完整或导出缺项，报告“已获取 X / 页面声称 N”，列出缺口；不要补造条目或声称检索了未访问的内部结果。
4. 对截图、复制文本或导出文件识别出的题名做人工核对。阅读顺序和编号以实际内容为准；避免把页面推荐论文、相似论文、聊天正文或“全部搜索结果”误并入“参考文献”。

## 文献核验

1. 对每条参考文献查找可访问的 Bohrium 详情页、DOI 记录、出版方、会议或期刊官网。核对题目、作者、正式发表出处、年份、DOI；标注预印本、网络首发或正式版本。优先保留原始 Bohrium 链接和核验链接。
2. 按 DOI 去重，无 DOI 时按题目、作者、年份核对；保留原始编号到去重后条目的映射。无法核实的字段写“未查到”，不能用 Bohrium 自动生成的简介替代作者摘要，也不能将 AI 文本当作论文结论。
3. 文献数量较大时，先确保引用列表完整且有可访问链接，再逐篇核验题录。若篇数或访问限制使逐篇核验未完成，明确标出“已核验”和“待核验”，不要把整份清单标为已核验。用户要求全部文献时，篇数多本身不是截断理由。

## 综述与交付

- 从 Bohrium 对话提取研究问题、检索词、综述的主题和文内引用关系；用自己的话整理研究背景、方法类别、代表工作、比较维度、主要分歧或局限及可进一步研究的问题。对核心论断附对应的已核验文献编号或链接。Bohrium 生成的综述是线索，不能未经核对就当作论文原文证据。
- 区分“Bohrium 对话的内容概要”和“基于已核验论文重新撰写的综述”。只读到摘要时标明“基于摘要”；读到全文时再讨论实验细节。不要整段复制网站综述或受版权保护的摘要。
- 输出至少包含：输入来源与访问日期；页面声称数量、实际获取数量、去重后数量、已核验数量；带编号的综述；完整已获取参考文献表（原始编号、题目、作者、出处、年份、DOI、Bohrium 链接、核验链接、核验状态）；缺失或无法访问的条目说明。若列表很长，可交付 CSV/Markdown 文件并在回答中摘要，不省略已获取条目。
- 若用户还要求国内外补充文献，在对话引用清单之外另设“补充检索”部分，依主 skill 的中英文检索流程查找；不要把新增文献算进 Bohrium 原始引用数。
