# Bohrium 对话结果整理

适用于用户要求读取 Bohrium 科学导航或学术搜索对话，整理其研究问题分析、综述、文内引用、右侧参考文献或“全部搜索结果”。这是读取用户可访问内容并核验文献的工作流，不代表接入 Bohrium 私有数据库或复现其内部搜索。

## 获取与界定范围

1. 优先使用用户给出的对话分享链接、批量引用导出文件或页面内容。若所用 Bohrium 模式在参考文献面板提供批量导出且工具可操作，优先导出，再用页面核对文内引用和遗漏；不要假定每个模式都有该功能，也不要猜测导出格式。若用户已在可控制的浏览器中打开对话，且工具能访问该页面，可读取页面；遵守登录与访问限制，不索取密码、会话令牌或绕过验证。截图只能证明可见区域的内容。
2. 先记录对话主题、生成日期（若可见）、页面显示的“参考 N 篇”等计数，以及用户需要的范围。将**正文实际引用**、**参考文献面板**、**全部搜索结果**分别作为集合记录；按用户要求选择集合，不能把一个集合冒充另一个。面板来源可能是论文、预印本、专利、学者资料、百科或网页；按实际类型分类，非论文不写成论文。
3. 对可访问的目标集合逐页或滚动读取到末尾，保留原始编号、来源类型、题目或名称、作者、年份、出处、详情链接、文内引用标记及导出记录标识（若有）。用导出、面板和正文交叉核对缺项与重复项。仅在实际获取全部条目且可与目标集合计数对上时声明“全部”。若页面只显示前若干条、分页无法访问、截图不完整或导出缺项，报告“已获取 X / 页面声称 N”，列出缺口；不要补造条目或声称检索了未访问的内部结果。
4. 对截图、复制文本或导出文件识别出的题名做人工核对。阅读顺序和编号以实际内容为准；避免把页面推荐论文、相似论文、聊天正文或“全部搜索结果”误并入“参考文献”。保留原始数据和访问日期，使后续核对可复现。

## 文献核验

1. 对论文和预印本查找可访问的 Bohrium 详情页、DOI 记录、出版方、会议或期刊官网，核对题目、作者、正式发表出处、年份、DOI；标注预印本、网络首发或正式版本。对专利、百科、学者资料和网页，使用对应的一手记录核对名称、发布者与日期，不强填 DOI 或期刊。保留原始 Bohrium 链接和核验链接。
2. 按 DOI 去重，无 DOI 时按题目、作者、年份核对；保留原始编号到去重后条目的映射。无法核实的字段写“未查到”，不能用 Bohrium 自动生成的简介替代作者摘要，也不能将 AI 文本当作论文结论。
3. 文献数量较大时，先确保引用列表完整且有可访问链接，再逐篇核验题录。若篇数或访问限制使逐篇核验未完成，明确标出“已核验”和“待核验”，不要把整份清单标为已核验。用户要求全部文献时，篇数多本身不是截断理由。

## 综述与交付

- 从 Bohrium 对话提取研究问题、检索词、综述的主题和文内引用关系；用自己的话整理研究背景、方法类别、代表工作、比较维度、主要分歧或局限及可进一步研究的问题。建立“综述论断 → 原始引用标记 → 已核验来源 → 证据位置”的对应关系。证据级别标为题录、摘要、全文或未找到；若可见引用追踪中的摘要句或 PDF 段落，用它定位原始证据，并核对该证据是否支持论断。对部分支持、冲突或无法判断的论断明确标注，不强行给出肯定结论。Bohrium 生成的综述是线索，不能未经核对就当作论文原文证据。
- 区分“Bohrium 对话的内容概要”和“基于已核验论文重新撰写的综述”。只读到摘要时标明“基于摘要”；读到全文时再讨论实验细节。不要整段复制网站综述或受版权保护的摘要。
- 输出至少包含：输入来源与访问日期；正文引用、参考文献面板、全部搜索结果各自可见的声称数量与实际获取数量；目标集合的去重后数量、已核验数量；带编号的综述；论断与证据对应表；完整已获取来源表（原始编号、来源类型、题目或名称、作者或发布者、出处、年份、DOI/其他标识符、Bohrium 链接、核验链接、核验状态）；缺失或无法访问的条目说明。若列表很长，可交付 Markdown/CSV 文件并在回答中摘要，不省略已获取条目。用户需要文献管理器导入时，可再生成 BibTeX 或 RIS；只导出已确认的字段，缺少必要信息的条目保留在 CSV 并标记待核验，不编造元数据。
- 若用户还要求国内外补充文献，在对话引用清单之外另设“补充检索”部分，依主 skill 的中英文检索流程查找；不要把新增文献算进 Bohrium 原始引用数。

## 完整性检查

交付前核对：目标集合的页面计数与实际获取数能否对应；正文引用标记是否都有来源记录；去重前后的编号是否可追溯；每条综述核心论断是否有证据状态；导出文件条目数与报告一致。任何一项无法完成时，在结果中说明具体缺口。真实对话或导出样本尚未提供时，不宣称已通过 Bohrium 端到端验证。
