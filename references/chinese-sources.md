# 中文文献查询网站

以下为检索入口，按学科选用；不要把数据库收录误写成论文的发表出处。访问和全文权限可能取决于机构订阅，逐篇以当前页面为准。

| 网站与入口 | 类型及覆盖重点 | 何时使用与核验注意 |
|---|---|---|
| [中国知网 CNKI](https://kns.cnki.net/) | 综合学术数据库；中文期刊、学位论文、会议论文等 | 中文主题首轮检索、追踪作者和关键词；主站可能要求登录。其[期刊网络出版平台](https://www.cnki.net/)上的单刊页也可核对摘要、正式年份和 DOI。不要把网络首发日期当作卷期年份。 |
| [万方数据知识服务平台](https://www.wanfangdata.com.cn/) | 综合数据库；期刊、学位、会议、科技报告、标准等 | 与知网交叉补漏，尤其查学位论文及应用研究；题录与全文权限分开判断。 |
| [维普网](https://www.cqvip.com/) / [高级检索](https://www.cqvip.com/advancesearch) | 中文期刊为主，也提供学位、会议等类型检索 | 按篇名、作者、刊名、DOI 复核；适合补齐知网或万方遗漏的中文期刊记录。 |
| [国家科技图书文献中心 NSTL](https://www.nstl.gov.cn/science_search.html) | 中外文科技期刊、会议录、学位论文、科技报告、专利、标准等题录 | 理工、工程与交叉学科补充检索；题录可用于发现，全文服务可能需注册或文献传递。 |
| [国家哲学社会科学文献中心](https://www.ncpssd.org/) | 哲学、社会科学及人文领域期刊等文献 | 社科、人文、政策与管理研究优先补充；不要拿它代替工程或医学专业库。 |
| [SinoMed 中国生物医学文献服务系统](https://www.sinomed.ac.cn/lw/advancedSearch.jsp) | 生物医学中外文整合检索，支持主题词和高级检索 | 医学、公共卫生和生命科学课题；与 PubMed 互补。部分功能或全文需要登录。 |
| [中国科技论文在线](https://www.paper.edu.cn/) | 科技论文首发、开放获取期刊论文及相关学术资源 | 查理工科新成果和可读全文；首发稿与正式期刊版要区分，若已有正式版本优先引用正式版。 |
| [ChinaXiv](https://chinaxiv.org/) | 国内预印本和开放存档，含中文与英文稿件 | 跟踪尚未正式发表的工作；明确标注“预印本”，核对是否已有同行评审后的正式版本。 |

## 选站建议

- 普通中文主题：知网 + 万方；结果少或元数据有冲突时加入维普及期刊官网。
- 理工与工程：在上述综合库外加 NSTL；查近期开放稿件时再看中国科技论文在线、ChinaXiv。
- 医学：加 SinoMed；社会科学与人文：加国家哲学社会科学文献中心。
- 查到题目后打开论文详情页及期刊官网，记录实际读到的是题录、作者摘要还是全文。需要 DOI、卷期和正式出版年时，以出版方或期刊官网为主要核验依据。
