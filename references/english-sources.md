# 英文文献查询网站

按研究领域选 2 至 4 个互补入口即可。聚合索引帮助发现论文，出版方或会议官网用于确认正式版本；预印本须单独标注。平台可检索不等于免费获得全文，访问权限以当前页面为准。

## 跨学科发现与元数据

| 网站与入口 | 类型及覆盖重点 | 何时使用与核验注意 |
|---|---|---|
| [Bohrium](https://www.bohrium.com/) | 学术发现与论文详情、研究辅助工具 | 快速找候选论文及相关研究；AI 生成 Summary 与论文作者摘要分开，不用它单独核定 DOI 和出版信息。页面触发验证时改查出版方。 |
| [Google Scholar](https://scholar.google.com/) | 跨学科学术搜索；论文、学位论文、图书、预印本等 | 宽范围找线索和被引版本；结果混合多种文献类型，逐条核对原始来源。 |
| [OpenAlex](https://openalex.org/works) | 开放学术元数据与引用关系索引 | 按主题、年份、机构、文献类型筛选和发现相关论文；核对出版方记录，摘要并非每篇都有。 |
| [Semantic Scholar](https://www.semanticscholar.org/) | 跨学科论文搜索与引文关联 | 追踪相似论文、参考文献与施引文献；摘要和元数据仍需与原始出版页核对。 |
| [Crossref Metadata Search](https://search.crossref.org/) | DOI 注册元数据查询 | 按题目、作者或 DOI 确认标识符和出版元数据；它不是全文库，未查到 DOI 不等于论文不存在。 |
| [Web of Science](https://www.webofscience.com/) | 跨学科引文索引，含期刊、会议和图书记录 | 系统检索、引文追踪与计量分析；可见范围依机构订阅，不把未访问的结果写成已检索。 |
| [Scopus](https://www.scopus.com/) | 摘要与引文数据库 | 学科检索、作者与机构分析、引文追踪；可能需要机构权限，与 Web of Science 的覆盖和计数不能直接混同。 |
| [DOAJ](https://doaj.org/) | 开放获取期刊和论文目录 | 寻找可访问的同行评审开放期刊论文；收录范围限开放获取期刊，不代表整个领域。 |

## 学科数据库与文献目录

| 网站与入口 | 类型及覆盖重点 | 何时使用与核验注意 |
|---|---|---|
| [PubMed](https://pubmed.ncbi.nlm.nih.gov/) | 生物医学和生命科学文献题录与摘要 | 医学、健康、生命科学检索；PubMed 本身不是期刊全文库，全文常链接至出版方或 PMC。 |
| [Europe PMC](https://europepmc.org/) | 生命科学文献、部分全文和预印本 | 与 PubMed 互补，寻找开放全文及相关数据；辨别预印本与正式发表版本。 |
| [IEEE Xplore](https://ieeexplore.ieee.org/) | 电气、电子、通信、控制、计算机领域的 IEEE 期刊、会议及标准 | 无人机、机器人、算法与工程论文重点检索；部分全文需订阅。 |
| [ACM Digital Library](https://dl.acm.org/) | 计算机科学与信息技术期刊、会议论文 | 算法、人工智能、人机交互和软件领域；会议论文的正式会议名称、年份与 DOI 以论文页为准。 |
| [dblp](https://dblp.org/) | 计算机科学书目目录 | 核对作者、会议、期刊及版本，发现同一作者相关论文；主要提供书目信息，阅读摘要与全文需转至论文来源。 |
| [ERIC](https://eric.ed.gov/) | 教育研究文献数据库 | 教育学、教学法、教育技术研究；可筛同行评审和可用全文，记录类型包括期刊文章与研究报告。 |
| [JSTOR](https://www.jstor.org/) | 学术期刊、图书及历史原始资料平台 | 人文社科及历史文献检索，尤其适合回溯早期研究；部分馆藏需订阅，开放内容可另行筛选。 |

## 出版平台与开放稿件

| 网站与入口 | 类型及覆盖重点 | 何时使用与核验注意 |
|---|---|---|
| [ScienceDirect](https://www.sciencedirect.com/) | Elsevier 出版的期刊及图书内容 | 核对正式论文的摘要、卷期页码和 DOI；并非跨出版社的完整索引，全文权限视文章而定。 |
| [SpringerLink](https://link.springer.com/) | Springer Nature 期刊、图书与会议论文 | 核对出版版本和引用格式，尤其工程、计算机与自然科学内容；部分全文需订阅。 |
| [Wiley Online Library](https://onlinelibrary.wiley.com/) | Wiley 期刊及图书内容 | 核对正式版本、作者、卷期与 DOI；全文权限视文章而定。 |
| [arXiv](https://arxiv.org/) | 物理、数学、计算机、统计等学科预印本 | 跟踪最新方法和可读稿件；arXiv 明确说明其材料并未由平台同行评审。若已正式发表，合并版本并优先引用正式版。 |
| [bioRxiv](https://www.biorxiv.org/) | 生命科学预印本 | 跟踪最新生物学研究；稿件未经过正式同行评审，检查后续期刊版本。 |
| [medRxiv](https://www.medrxiv.org/) | 医学和健康科学预印本 | 跟踪尚未正式发表的医学研究；不得把预印本结论当成已确证的临床证据。 |
| [SSRN](https://papers.ssrn.com/) | 早期研究、工作论文与预印本，社会科学等学科较常用 | 经济、法律、管理等领域补充检索；检查稿件状态及是否已有正式发表版。 |

## 选站建议

- 普通跨学科问题：Bohrium + Google Scholar 或 OpenAlex；用 Crossref、出版方或会议官网核对关键信息。
- 无人机、控制、计算机：Bohrium + IEEE Xplore；算法方向再加 ACM Digital Library、dblp、arXiv。系统性引文检索可在具备权限时加入 Web of Science 或 Scopus。
- 医学与生命科学：PubMed + Europe PMC；开放获取补 DOAJ。新成果可检索相关预印本，但需明确版本状态。
- 教育研究：ERIC；人文社科与历史文献：JSTOR；早期经济、法律和管理研究可加 SSRN。
- 使用 ScienceDirect、SpringerLink、Wiley 等出版平台核对它们实际出版的论文，不把某出版社的结果当作全领域覆盖。
